# Tavupeli v4

Cooperative Finnish syllable-counting adventure board game built for 65" Clevertouch displays, tablets, and laptops.

## Highlights (v4)
- Cohesive Scandinavian ink storybook illustration set (20 word cards + 21 board, landmark, Bear, and scenic map WebP assets)
- Dynamic orthogonal board scaling cleanly from 20 to 45 squares with inside-square station/twist art, empty-square stepping pebbles, organic ground patches, quiet turn cues, and curved dotted `Taikaportti` portal arcs
- Taputus-only syllable counting (`1 → 0` beat-dot step-back) with `Valmis` → numeral + *tavuviiva* reveal → player-colored `Liiku` button, then clean board glide
- Lurking Style B Bear behind Square 1, warm-stone Bear cards with matching paw prints, and zero-flash Setup
- Self-hosted SIL Andika early-reader font (`fonts/andika-*.woff2`) and full offline PWA caching (`tavupeli-cache-v5`)
